# 0027. 履歴のセリフに、気持ちの顔を添える

- Date: 2026-09-22
- Status: Accepted（2026-09-25: Mac の履歴の吹き出しに尻尾を付けることを「追記」の節に加えた）

## Context

[ADR 0026](0026-a-feeling-on-each-line.md) で、natsumi のセリフ（reply・notice）がセリフごとの気持ち `expression` を
持つようになった。候補はアバターの表情と同じ 8 つで、欄が無いもの（記録を始める前のセリフ）と知らない値は「不明」と読む。
Mac の履歴にどう見せるかは、同 ADR で範囲の外として残した。

キャラクターは spritesheet のアニメーションで描いている（[ADR 0010](0010-mac-app-structure.md)）。
履歴の行ごとにアニメーションを動かすのは重く、小さく描くと表情も読み取れない。
一方で、利用者は表情ごとの顔のアイコン（1 枚の静止画）を 8 つ用意した。iPhone のクライアントの設計でも、
アニメーションはメインの画面だけにして、履歴はこのアイコンで描く。

## Decision

### 1. 顔のアイコンはアバターのものとして持つ

アイコンはアバターのディレクトリに置き、`avatar.json` の `icons` に表情ごとのパスを書く
（`"icons": { "happy": "icons/happy.webp", … }`）。

- 利用者は自分のアバターを持ち込める。顔の絵はキャラクターの絵と一緒に替わるべきなので、アプリには埋め込まない。
- パスはアバターのディレクトリの中に限る（空・絶対パス・`.` や `..` を含むものは誤り）。
- 書かれていない表情と、読めないファイルは「アイコンなし」になり、誤りにしない。キャラクターはアイコンがなくても動く。
- 既定のアバターの絵は、1024px の PNG を 512px の WebP にして `mac/Avatars/natsumi/icons/` に置く。
  履歴で描く大きさ（最大 52pt、Retina で 104px）にも、iPhone のログイン画面の大きさにも足りる。

### 2. natsumi のセリフの横に丸い顔を、いちばん新しいセリフだけ大きく描く

- natsumi のセリフ（reply・notice）の横に、そのセリフの気持ちの顔を丸く切り抜き、インクの輪郭で描く。
  本人のメッセージには付けない。
- いちばん新しい natsumi のセリフの顔だけを大きくする（52pt。ほかは 28pt）。後ろに本人のメッセージが続いていても、
  natsumi のセリフの中でいちばん新しいものを選ぶ。いま彼女がどんな気持ちで話したかが、履歴の末尾で目に入る。
- 「考え中…」の行には thinking の顔を添える。
- 顔には、ポインタを重ねると「気持ち: うれしい」のように気持ちの名前が出る。

### 3. 不明は neutral の顔を薄くして描く

気持ちが不明なセリフは、neutral の顔を薄く（不透明度 0.4）描く。ポインタを重ねると「気持ちの記録なし」と出る。

- 記録を始める前のセリフはすべて不明なので、しばらくは履歴のほとんどが不明になる。点線の丸を並べるより、
  彼女の顔がそろっている方が履歴として読みやすい。
- それでも ADR 0026 のとおり、不明は「平静」ではない。濃さを変えて、気持ちが記録された neutral と見分けられるようにする。
- アバターに neutral の顔もないとき、または気持ちはあるがその表情の顔がないときは、点線の丸に「な」と描く。

### 4. どの顔をどの大きさで描くかは Props で決める

`HistoryRowProps` に `face`（`FaceProps`: 気持ち・大きいかどうか・ポインタを重ねたときの文言）を足し、
`UIProps.history` が導出する。View は Props と、`HistoryProps.avatar` から引いた絵を描くだけにする
（[ADR 0015](0015-mac-ui-passive-view-tree.md)）。導出は `NatsumiCore` にあるので、iPhone のクライアントでも同じ規則を使える。

## Consequences

- 履歴を読み返すと、natsumi のセリフごとに気持ちが顔で分かる。記録を始める前のセリフは、薄い neutral の顔で残る。
- アバターを持ち込む人は、`icons` を書かなければ顔はすべて点線の丸になる。アバターの README に書き方を残す。
- 表情の候補を増やすと、顔のアイコンも足す必要がある。足すまでは、その気持ちのセリフは点線の丸で描かれる。

## 追記（2026-09-25）: Mac の履歴の吹き出しの尻尾

- Mac の会話のウインドウの履歴で、吹き出しに尻尾を付ける。尻尾は吹き出しの下のほうから横へ出る。
  - natsumi のセリフ（返事も知らせも）の尻尾は左の顔を指す。
  - 本人のメッセージ（記録された行も、受付中の行も）の尻尾は右を指す。
- 知らせの行も、返事と同じ形にする。どちらも顔を添えた彼女のセリフであり、黄色い紙と「お知らせ」の印で見分けられる。
- 輪郭は、箱と尻尾でひと続きにする。デスクトップの返事の吹き出し（[ADR 0010](0010-mac-app-structure.md)）と同じく、角丸の箱と三角形を合わせた 1 つの形を塗り、同じ形で輪郭を描く。
  - 顔は吹き出しの下の辺にそろえてあるので、尻尾の根は下の角の丸みの上に置く。先はそれより少し下に置く。
- 尻尾の分だけ、その側の内側の余白を広げる。本文の描き方（[ADR 0038](0038-links-in-what-she-says.md) の `NSTextView`）と高さの計測は変えない。
- iPhone の履歴は変えない。iPhone は、話し手の側の角を小さくする形のまま。
