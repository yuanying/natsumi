# 0042. ポッポさんは実在する絵文字ならどれでもリアクションに付ける

- Date: 2026-09-26
- Status: Accepted

## Context

natsumi はポッポさんへの依頼でリアクションを付けられる。リアクションは本文を書かないので、判定も本人の承認も通さない
（[ADR 0039](0039-slack-as-files-and-a-scored-dove.md)）。その代わりに、使える絵文字をサーバーの持つ候補の一覧（設定の `slack.reactions`、
既定は `+1`・`eyes`・`pray`・`white_check_mark`・`bow`・`tada`）に限り、候補に無いものはその場で断っていた
（[ADR 0040](0040-the-dove-sends-what-the-judge-passes.md)）。

候補に絞った狙いは、判定を通らない出力で意味を持ちすぎないようにすることだった。ところが、既定の候補にも ✅（`white_check_mark`）のように
「承知した」「済んだ」と読める絵文字が既に入っている。候補に絞っても、判定を通らずに意味を伝えることは防げていなかった。
一方で、候補の外の絵文字（場に合った顔や、ワークスペースで使われているカスタム絵文字）は付けられず、natsumi の返しが単調になっていた。

## Decision

### 1. 実在する絵文字ならすべて付ける（本人の決定、2026-09-26）

- 付けられるのは、次のどちらかに名前がある絵文字である。無い名前だけを断る。
  - 標準の絵文字。Slack での名前（別名を含む。例: `+1` と `thumbsup`）で書く。肌の色を取るものは `::skin-tone-2` から `-6` を付けてもよい。
  - そのワークスペースのカスタム絵文字（`emoji.list`）。別名（`alias:`）も含む。
- 判定も本人の承認も通さない点は変えない（ADR 0039 のまま）。
- カスタム絵文字に文字の絵文字（例: `:lgtm:`）があれば、判定を通らない一言として付けられる。本人はこれを承知している（テストの段階）。
- 断る文は、その名前の絵文字が無いことと、名前の確かめ方が natsumi 向けのマニュアル（`manual/slack.md`）にあることを伝える。
  候補の一覧はもう無いので、断る文に絵文字を並べない。

### 2. 標準の絵文字の名前はリポジトリに置く

- 名前は emoji-datasource（iamcal/emoji-data、MIT License）から生成し、サーバーのソースとしてリポジトリに置く。
  このデータは Slack の短い名前をそのまま持っている。生成の手順はスクリプトにある。
- パッケージを依存にしない。中身の大半は画像で、展開すると 28 MB あり、名前を引くためだけに本番の image に入れたくないからである。
- 2 人の絵文字に別々の肌の色を付ける形（2 つの色の組）は受け付けない。

### 3. カスタム絵文字はワークスペースごとに読み、しばらく持つ

- 起動したときに、ワークスペースごとに `emoji.list` を 1 度読む。
- 読んだ一覧は持っておき、1 時間より古くなったら、次に使うときに読み直す。
- 一覧に無い名前を頼まれたら読み直す。ただし前に読んでから 1 分は読み直さない。知らない名前が続いても、読むのは 1 分に 1 度までである。
- 同じワークスペースを同時に読むのは 1 度だけにする。
- 読めなかったとき（`emoji:read` が無い `missing_scope` など）は、前に読めた一覧があればそれを、無ければ標準の絵文字だけで確かめる。
  読めなかったことも 1 度読んだものとして数え、すぐには読み直さない。
  ログには、ほかの Slack の失敗と同じ形で、ワークスペース・メソッド・Slack のエラーのコード（足りない scope）を 1 行で出す
  （例: `slack (work): the custom emoji could not be read (emoji.list: missing_scope, needed emoji:read)`）。
- Slack App に `emoji:read` の scope が要る。

### 4. 設定の `slack.reactions` をやめる

- 設定に `slack.reactions` が書いてあれば、起動を拒む。消すように言い、この ADR を示す。
- 黙って無視すると、書いた人は候補に絞れていると思い込む。設定の未知のキーで起動を拒む作りにも揃う。

### 置き換える既存の決定

- ADR 0039「リアクション」: 置き換え:「絵文字はサーバーの持つ候補の一覧に限る」。
- ADR 0040「リアクション」: 置き換え:「絵文字は設定の候補の一覧に限る。候補に無いものは、その場で断り、候補を示す」。

## Consequences

- natsumi は、場に合った標準の絵文字とワークスペースのカスタム絵文字を付けられる。
- 判定を通らずに付けられるものが広がる。意味を持つ絵文字は前から付けられたので、守りが弱まる幅は小さいが、
  文字のカスタム絵文字は短い一言として付けられるようになる。
- `emoji:read` を足して入れ直すまでは、カスタム絵文字は断られ、起動のたびにログに 1 行出る。標準の絵文字は付けられる。
- Unicode に新しい絵文字が入り、Slack が名前を足したら、生成し直すまでその名前は断られる。
- `slack.reactions` を書いていた設定は、消すまで起動しない。
